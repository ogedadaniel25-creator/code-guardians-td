# Code Guardians TD — Full HD v3

## Como executar
Instale Python 3.10 ou superior e execute `INICIAR_WINDOWS.bat`, ou use `pip install -r requirements.txt` e `python main.py`.

## Controles
- **E**: Pulso EMP. Custa 200 créditos, atordoa inimigos por 2 segundos e recarrega em 25 segundos.
- **H**: Mostra/oculta o painel de atalhos.
- **F11**: Alterna tela cheia.
- **F12**: Salva captura em `capturas/`.
- **ESC**: Pausa/retoma.

## Vídeo
Saída Full HD 1920 × 1080, com renderização lógica 1280 × 720 para compatibilidade com a interface original. Em telas menores, adapta-se ao tamanho da janela.

## Observação
A inicialização foi testada por 10 segundos em modo sem janela gráfica. O teste visual no Windows ainda deve ser feito.
